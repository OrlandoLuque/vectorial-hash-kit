critters — spatial-index demos

Live demos for vectorial-hash-kit, a Rust spatial-index library. Watch the index split & merge in real time as critters move, hunt and attack — running right here in your browser via WebAssembly.

2D critters →

Predators & prey on a flat map. A live tuning panel and performance graphs; the index's leaf regions recolour as cells subdivide and merge. 3D

3D critters →

A cube world with GPU-instanced rendering. Press M to switch the index live (binary tree / octree / Morton grid / projection — all O(1)-relocated via stable handles).

Click the canvas to give it keyboard focus. The first load fetches ~1 MB of WebAssembly. Needs a WebGL2-capable browser (any recent desktop browser).
