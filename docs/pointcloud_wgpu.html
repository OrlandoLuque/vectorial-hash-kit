Scanning the scene…
A large static, strongly skewed point cloud — dense on surfaces, empty in between — which is the case a median-split k-d tree is built for. Every point is coloured by its local density, computed with a k-NN query per point; M rebuilds the cloud on a different structure and re-runs the whole pass, so the build and k-NN numbers are measured live (and cross-checked against the previous structure).
