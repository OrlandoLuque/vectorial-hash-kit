# Siege demo — 3D model credits

The `siege` demo uses third-party low-poly models. They are **not** covered by
the repository's own licence — each keeps the licence below. Models live in this
folder (`crates/vectorial-hash-demos/assets/siege/`) as glTF/`.glb`.

Almost everything is **CC0** (public domain — attribution not legally required,
but we credit anyway). The **one exception is the Witch**, which is **CC-BY 3.0**
and therefore *must* be attributed. The in-demo credits modal / panel surfaces
this list.
